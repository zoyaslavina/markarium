# Security policy

## Supported version

Security fixes are applied to the current release on the `main` branch.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** private-reporting flow for this repository. Do not include exploit details, private documents or sensitive data in a public issue.

Useful reports include:

- the affected browser and Markarium.md version;
- a minimal Markdown or annotation JSON sample with private content removed;
- the expected and observed behaviour;
- whether the issue can execute active content, access a network resource, expose local data or modify a file without clear user action.

You should receive an acknowledgement through GitHub within seven days. Public disclosure should wait until a fix or mitigation is available.

## Security boundary

The standalone edition is intended to make no automatic network request. Markdown is sanitized before display, remote document resources are blocked, unknown/local link schemes are made inert, and imported annotation records are validated. Files, downloads, clipboard writes and external links require explicit user action.

On browsers that implement the File System Access API, a handle for a file the user explicitly selected may be stored in local IndexedDB and reattached to a restored tab. Restoration only queries existing permission without prompting; Markarium requests access from an explicit Open/Edit/Save gesture and writes only from Done or Save. Safari/iPad does not receive this capability and continues to use explicit Share copy. Session undo/redo snapshots remain in memory, are bounded per document and are not persisted across page reloads.

Portable Markdown includes a fixed Agent Brief generated by Markarium.md. The brief contains status labels and numeric annotation counts only: it does not copy document text, annotation wording or other untrusted content into its guidance. It makes no editing request and explicitly defers to the user’s current prompt. The base64 annotation payload remains review data, not a separate task or executable application content. Base64 is portability, not encryption: anyone who receives the file can decode its embedded annotations.
