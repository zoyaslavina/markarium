Private is the default, not a setting.

The standalone edition has no account, analytics or telemetry. Its parser, sanitizer, formula renderer, fonts and interface assets are bundled into the HTML file.

  • Automatic network connections are denied by Content Security Policy.
  • Rendered Markdown is sanitized before it enters the document.
  • Remote document images are replaced with a blocked-resource notice.
  • Files, clipboard writes and external links require an explicit action.
Where do documents and annotations go?

They stay in browser storage or in files you explicitly open, save, import or export. The application itself does not upload document content. The hosted page is delivered by GitHub Pages, whose infrastructure has its own privacy practices.

Does it work offline?

Yes. Download the HTML file and open it directly from disk. No package installation or build process is required.

Can I inspect what is shipped?

Yes. The standalone source and production artifact are the same HTML file. Bundled third-party components and their licences are documented in the repository.
