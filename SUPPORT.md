# Markarium.md support

Markarium.md is maintained independently. Support is provided through the public
GitHub repository; there is no in-app account or support inbox.

## Get help or report a problem

Open the repository's
[issue chooser](https://github.com/zoyaslavina/markarium/issues/new/choose) for:

- a product problem or unexpected behaviour;
- an accessibility barrier;
- a documentation problem;
- a focused improvement request; or
- a privacy question that does not contain sensitive information.

For a suspected security vulnerability, use GitHub's private **Report a
vulnerability** flow described in [`SECURITY.md`](SECURITY.md). Do not publish exploit
details, private files or sensitive data in a public issue.

## What to include

- Markarium.md edition: web or desktop;
- app/version number or the date you downloaded the standalone HTML;
- operating system and browser, when relevant;
- Apple silicon or Intel for a Mac problem;
- input method or assistive technology, when relevant;
- what you expected and what happened; and
- minimal steps or a sample with all private and identifying content removed.

Never attach a confidential Markdown file, annotation export or screenshot
containing private document text. Portable review data can include the selected
quotation and surrounding context used to keep comments and tasks attached.

## Current platform notes

- The desktop 1.0 build supports Apple silicon Macs running macOS 12 or later.
- Chrome and Edge can save directly to an opened web-edition file when the File
  System Access API is available.
- Safari on iPad and iPhone saves a portable copy through the system share sheet;
  choose **Save to Files** and reopen that copy to continue later.
- The web workspace continues to work without a network after it has loaded, but it
  is not installed as an offline PWA. Load it before losing connectivity and save
  important work before closing Safari.
- Restored desktop tabs contain a private reading copy. Reopen the original file
  after restarting the app to renew native save and local-image access.

See [`README.md`](README.md), [`FEATURES.md`](FEATURES.md) and
[`ACCESSIBILITY.md`](ACCESSIBILITY.md) for the current capability and accessibility
records.

## Response expectations

Reports are reviewed on a best-effort basis. Acknowledgement or resolution time is
not guaranteed. Security reports follow the separate response guidance in
[`SECURITY.md`](SECURITY.md).
