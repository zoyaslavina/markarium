## Choose the right route

- **Using the reader or proposing an improvement:** `{{PUBLIC_SUPPORT_URL}}`
- **Reporting an accessibility barrier:** `{{ACCESSIBILITY_ISSUE_URL}}`
- **Reporting a security vulnerability:** use GitHub private vulnerability reporting as described in [`SECURITY.md`](SECURITY.md). Do not disclose it in a public issue.
- **Privacy question:** `{{PRIVACY_CONTACT_ROUTE}}`

## What to include in a public report

- the standalone version and browser;
- operating system and, when relevant, input method or assistive technology;
- what you expected and what happened;
- minimal reproduction steps;
- a sample with all private or identifying content removed.

Never attach a confidential Markdown file, annotation export or screenshot containing private document text to a public issue. Annotation data can include the selected quote and surrounding context used to keep feedback attached.

## Browser-specific saving

Chrome and Edge can save directly to an opened file when the File System Access API is available. Other browsers retain the reading, review and editing workflow but may save through a download. This difference is expected; report a problem if neither route works.
